2. Tài liệu API (Docs)

Base URL: https://api.bookservice.com/v1

Thêm header Authorization: Bearer {YOUR_API_KEY} vào mọi request.

Lấy danh sách thông tin các quyển sách (có phân trang).

Query Parameters:
  • page (int) - Số trang (mặc định: 1)
  • limit (int) - Số lượng kết quả mỗi trang (mặc định: 10)
Ví dụ cURL:
curl -X GET "https://api.bookservice.com/v1/books?page=1&limit=2" \
-H "Authorization: Bearer YOUR_API_KEY"
Sample Response (200 OK):
[
  {
    "id": "101",
    "title": "Clean Code",
    "author": "Robert C. Martin",
    "year": 2008
  },
  {
    "id": "102",
    "title": "Design Patterns",
    "author": "Erich Gamma, Richard Helm...",
    "year": 1994
  }
]

Lấy thông tin chi tiết một quyển sách cụ thể dựa trên ID.

Path Parameters:
  • id (string) - Mã định danh của quyển sách.
Ví dụ cURL:
curl -X GET "https://api.bookservice.com/v1/books/101" \
-H "Authorization: Bearer YOUR_API_KEY"
